# 🏠 Rental Property Management System

A full-stack web application designed to connect property owners and customers on a single platform. Property owners can list and manage rental properties, while customers can browse available properties, view rental details, and rent properties.

## 🚀 Features

### 👤 Owner

- Register and login
- Add rental properties
- Edit property details
- Delete properties
- View property status
- View customer rental information
- Contact customers

### 🧑‍💼 Customer

- Register and login
- Browse available properties
- Search and filter properties
- View property details
- View rent information
- Rent a property
- View rental information
- Contact property owners
- Update profile
